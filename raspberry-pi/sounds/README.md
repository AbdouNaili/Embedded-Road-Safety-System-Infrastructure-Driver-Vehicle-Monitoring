# Sounds

Put the alert sounds here (WAV files). The app looks for these names:

- `baillement.wav`
- `cedez_le_passage.wav`
- `chaussee_degradee.wav`
- `fault_brake.wav`
- `fault_cooling.wav`
- `fault_delayed_brake.wav`
- `fault_fuel.wav`
- `fault_harsh_accel.wav`
- `fault_harsh_brake.wav`
- `fault_loss_control.wav`
- `fault_turbo.wav`
- `fault_voltage.wav`
- `feu_rouge.wav`
- `feu_vert.wav`
- `mains_volant.wav`
- `passage_pietons.wav`
- `ralentisseur.wav`
- `somnolence.wav`
- `stop.wav`
- `succession_de_virages.wav`
- `vitesse_100.wav`
- `vitesse_30.wav`
- `vitesse_40.wav`
- `vitesse_60.wav`
- `vitesse_80.wav`
- `vitesse_depassee.wav`

A missing file is skipped, and its name is printed in the console.
